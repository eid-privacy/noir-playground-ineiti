# Noir Playground

This is a throwaway playground to have a look at noir...
It has the following directories:

- `issuer` - the python code to create the credentials
- `creds` - where the credentials and the private key of the issuer are stored
- `circuit` - hosts the different circuits I want to play around with
- `test` - code to actually execute the circuits generated by noir.

## Issuer

The code for the issuer is in the `./issuer` directory.
The issuer is a simple infrastructure and has a private/public key pair.
It creates credentials in different formats with the following fields:

- firstname, lastname - utf8-strings
- date of birth - 64 bit integer of the seconds since / before the unix epoch
- secret salt - 256 bit random value
- device key - an ECDSA P-256 public key
- end of validity - timestamp of validity end, as date of birth
- issuer signature - the signature of the issuer over the above fields

## Credentials

The credentials are in subdirectories of the `./creds` directory.
For this first test, I would like to have two different types of credentials:

1. JSON based - every attribute is a field/value in the json
2. Fixed size - every field has a constant size for all credentials, and the
values are filled in accordingly

The different credential types are in sub-directories.

The public/private key data of the issuer is in the `./creds` directory in a
format which is easy to use in python, rust, and javascript.

## Circuits

Circuits are in the `./circuit` directory.
The most interesting part.
I want to try out different circuits, so there needs to be some structure:

- first level: name of the credential format (json/fixed)
- second level: type of circuit (issuer signature, holder binding, ...)
- third level: versions (v01, v02, optimized_something)

## Test

Tests are in the `./test` directory.
Just to make sure we're actually doing the right thing.
The subdirectories should reflect the structure of the `./circuit`
directory.
Common code can be directly in the `./test` directory.

# How to run it

## Running Tests

Follow these steps to run the noir circuit tests:

1. **Enter the devbox environment** (if not already in it):
   ```bash
   devbox shell
   ```

2. **Navigate to a specific circuit directory** you want to test:
   ```bash
   cd circuit/[credential_format]/[circuit_type]/[version]
   ```

   For example:
   ```bash
   cd circuit/json/signature/v01
   ```

3. **Run the circuit test**:
   ```bash
   nargo test
   ```

4. **To test all circuits**, you can run tests from the root directory:
   ```bash
   # Test all circuits recursively
   find circuit -name "Nargo.toml" -execdir nargo test \;
   ```

5. **To generate and verify proofs**:
   ```bash
   # Generate proof
   nargo prove

   # Verify proof
   nargo verify
   ```

**Note**: Make sure you have the required credential files in the `creds/` directory before running tests that depend on them.
